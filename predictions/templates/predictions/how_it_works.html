How we turn clues into a percent

Think of each clue as worth some points. The model learned from thousands of past games how many points each clue should be worth. Here is the recipe:

  1. Start with a base number. This is the starting point before looking at any clue.
  2. Add up the points. For each clue, multiply the clue's value by its weight (its points), then add them all together. A clue with a big positive weight pushes toward Team A winning. A negative weight pushes toward the other team.
  3. Squish it into 0%–100%. The total can be any number, so we run it through an S-shaped curve (called the logistic curve) that turns it into a friendly percent between 0% and 100%. A big positive total becomes close to 100%; a big negative total becomes close to 0%; near zero becomes about 50–50.
  4. Make the parts add to 100%. For sports with draws, we do this for Team A win, Draw, and Team B win so the three chances add up to 100%.

The model's confidence is just how far apart the top two chances are. If one result is 80% and the next is 12%, that's high confidence. If they're 38% and 34%, that's low.
